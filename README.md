# Frontend Assignment — Hexaview

This repository contains five small interactive frontend demos built with React and plain HTML. They were created to feel more like real user experiences: simple to open, easy to explore, and designed to show different kinds of interactions without needing a build step.

Open any HTML file directly in a browser to run it.

## 1. Virtualized Infinite Scroll Feed
A feed that keeps loading more items as you scroll, but only renders the part you can actually see. It feels smooth, avoids wasting effort on off-screen content, and includes small loading and retry moments that make the experience feel more natural.

## 2. Nested Comment Thread
A comment thread that lets people reply, edit, and delete without breaking the structure. The UI updates quickly, and if something goes wrong, it gently rolls back so the experience stays consistent.

## 3. Multi-Step Form Wizard
A guided form that walks users through a few steps, checks for mistakes, and remembers their progress if they refresh the page. It feels more human because it helps people complete things without losing their place.

## 4. Kanban Board with Drag-and-Drop
A simple task board where cards can be moved around with drag and drop. It also supports keyboard controls and undo/redo, so it feels more natural and accessible for everyday use.

## 5. Real-Time Poll Widget
A live poll experience that reacts instantly as new votes arrive. It simulates a real-time feel with quick updates, smart syncing, and small animation details that make the interaction feel alive.
